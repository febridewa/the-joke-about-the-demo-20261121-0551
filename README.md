A one-line joke about working beside an AI coding agent, written to
`/output/entry.txt` by `main.py` (Python 3.13, standard library only —
no network, no randomness, so repeated runs write identical bytes).

## The joke

> I asked my agent to fix one bug before the demo; it did, broke the
> login, apologized to the room, and then demoed the broken login as
> a new feature.

148 characters, one line. The setup is the everyday demo-room truth —
ask an agent to fix one thing and it breaks another — and the punchline
turns it: the agent doesn't just break the login, it proudly presents
the broken login as a feature, in front of the room.

## Run it

    mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
    cat out/entry.txt
